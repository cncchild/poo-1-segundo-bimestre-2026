Programación Orientada a Objetos I
Segundo Bimestre 2026

Repositorio que reúne las actividades desarrolladas durante el segundo bimestre de la asignatura Programación Orientada a Objetos I, aplicando los principales conceptos de la programación orientada a objetos mediante el desarrollo progresivo del proyecto Llanquihue Tour.

Cristian Contreras

Carrera: Desarrollo de Aplicaciones

Profesor: Eithel Klauss González Rojas

# Contenido del repositorio

| Proyecto | Semana | Descripción |
|----------|--------|-------------|
| FormativaSemana1 | Semana 1 | Introducción a la Programación Orientada a Objetos, clases, objetos y encapsulamiento. |
| Sumativa1S3 | Semana 3 | Modelado de clases, composición, gestores de datos y organización inicial del sistema. |
| LlanquihueTour1 | Semana 4 | Gestión de reservas, lectura de archivos externos y organización modular del proyecto. |
| LlanquihueTour | Semana 5 | Colecciones dinámicas, filtros, búsquedas, Maven y documentación del proyecto. |
| LlanquihueTourS6 | Semana 6 | Implementación de herencia simple mediante una jerarquía de servicios turísticos y sobrescritura de métodos. |
| LlanquihueTourS7 | Semana 7 | Aplicación de polimorfismo, colecciones genéricas y recorrido de objetos mediante referencias a la superclase. |
| LlanquihueTourApp | Semana 8 | Interfaces, polimorfismo, `instanceof`, colecciones genéricas e interfaz gráfica (GUI). |


# Competencias desarrolladas

Durante este bimestre se trabajó con:

- Programación Orientada a Objetos.
- Clases y objetos.
- Encapsulamiento.
- Composición.
- Herencia simple.
- Clases abstractas.
- Polimorfismo.
- Sobrescritura de métodos (@Override).
- Interfaces.
- Colecciones ArrayList.
- Colecciones genéricas.
- Lectura de archivos externos.
- Búsquedas y filtros.
- Validación mediante instanceof.
- Interfaz gráfica (Swing GUI).
- Organización modular mediante paquetes.
- Documentación JavaDoc.
- Gestión de proyectos con Maven.
