# LlanquihueTourS7

## Objetivo

Desarrollar una aplicación en Java utilizando los principios de la programación orientada a objetos, aplicando polimorfismo, sobrecarga y sobrescritura de métodos para gestionar servicios turísticos mediante una colección de objetos.

## Clases creadas

### Paquete model
- Servicio
- Tour
- Transporte
- Guia

### Paquete data
- GestorServicios

### Paquete ui
- Main

## Tecnologías utilizadas

- Java 25
- Apache Maven
- NetBeans IDE

## Ejecución del proyecto

1. Abrir el proyecto **LlanquihueTourS7** en NetBeans.
2. Esperar que Maven cargue el proyecto.
3. Ejecutar la clase principal ubicada en:

   `cl.llanquihueTourS7.ui.Main`

También es posible ejecutar el proyecto desde Maven utilizando la configuración definida en el archivo `pom.xml`.
