# LlanquihueTourApp - Sumativa 1

## Descripción

Este proyecto corresponde a la primera evaluación sumativa de la asignatura **Desarrollo Orientado a Objetos I**. Su objetivo es modelar un sistema básico para la agencia de turismo **Llanquihue Tour**, aplicando los principios fundamentales de la Programación Orientada a Objetos, como encapsulamiento, composición, reutilización de clases y organización modular del código.

## Objetivo

Diseñar e implementar un modelo de clases que represente las personas vinculadas a la agencia de turismo, organizando el proyecto en paquetes y aplicando buenas prácticas de desarrollo orientado a objetos para facilitar futuras ampliaciones del sistema.

## Estructura del proyecto

### Paquete `model`

- Persona
- Direccion
- Empleado

### Paquete `app`

- Main

## Conceptos aplicados

- Programación Orientada a Objetos.
- Encapsulamiento.
- Composición entre clases.
- Constructores.
- Métodos getters y setters.
- Sobrescritura del método `toString()`.
- Organización del proyecto mediante paquetes.

## Tecnologías utilizadas

- Java
- IntelliJ IDEA

## Ejecución del proyecto

1. Abrir el proyecto en IntelliJ IDEA.
2. Compilar el proyecto.
3. Ejecutar la clase principal:

   `app.Main`

4. Observar en la consola la creación de los objetos y la información generada mediante el método `toString()`.
