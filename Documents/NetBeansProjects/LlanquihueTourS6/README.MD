# LlanquihueTourApp - Semana 6

## Objetivo

Implementar una jerarquía de clases aplicando herencia simple en Java para representar los distintos servicios turísticos ofrecidos por la agencia Llanquihue Tour. El proyecto utiliza una superclase con atributos comunes y subclases especializadas, aplicando reutilización de código, constructores con `super()` y sobrescritura del método `toString()`.

## Clases creadas

### Paquete model

- ServicioTuristico
- RutaGastronomica
- PaseoLacustre
- ExcursionCultural

### Paquete data

- GestorServicios

### Paquete ui

- Main

## Conceptos aplicados

- Programación Orientada a Objetos.
- Herencia simple.
- Reutilización de código.
- Constructores con `super()`.
- Sobrescritura del método `toString()`.
- Organización del proyecto por paquetes.

## Tecnologías utilizadas

- Java
- Apache Maven
- NetBeans IDE

## Ejecución del proyecto

1. Abrir el proyecto **LlanquihueTourApp** en NetBeans.
2. Esperar que Maven cargue el proyecto.
3. Ejecutar la clase principal ubicada en:

   `cl.llanquihueTour.ui.Main`

4. Observar en la consola la información de los distintos servicios turísticos generados por la clase `GestorServicios`.
